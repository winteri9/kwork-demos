# Портфолио демо-проектов

Три адаптивных демо-сайта на чистых HTML, CSS и JavaScript. Внешние библиотеки и сборка не используются, каждый проект открывается двойным кликом по `index.html`.

## Проекты

| Папка | Тема | Что внутри |
|---|---|---|
| `project_quiz` | Натяжные потолки | Квиз-калькулятор из четырёх шагов, баллы и расчёт стоимости |
| `project_ai` | Стоматология «Улыбка» | Лендинг с ценами и плавающий чат-виджет на if/else |
| `project_forms` | Автоматизация заявок | Форма с fetch POST и Google Apps Script для Telegram |

## project_quiz

- Четыре шага: площадь, освещение, сроки, имя и телефон
- Баллы начисляются за каждый ответ, итоговая стоимость считается по ставке 1 000 ₽ за м²
- Проверка имени и телефона, итоговый экран с ценой
- Заявка выводится в `console.log` — демо-режим без сервера

## project_ai

- Сине-фиолетовый лендинг с ценами и блоками о клинике
- Кнопка чата в правом нижнем углу открывает окно переписки
- Ответы на чистом JavaScript: «Сколько стоит чистка?» → «4500 руб. Записать вас?», «Да» → запрос телефона
- На прочие сообщения бот отвечает «Передал администратору»

## project_forms

1. Замените `YOUR_SCRIPT_URL` в `index.html` на URL развёрнутого веб-приложения Google Apps Script.
2. В `Code.gs` укажите `TELEGRAM_TOKEN` и `CHAT_ID`.
3. Опубликуйте скрипт: «Развернуть» → «Новое развёртывание» → «Веб-приложение» с доступом «Все».
4. Форма отправляет JSON через `fetch POST`, скрипт пересылает заявку в Telegram.

Пока URL не заменён, форма работает в демо-режиме: данные печатаются в консоль и показывается экран успеха.

## Как открыть

Откройте любой `index.html` в браузере. Для `project_forms` при реальной отправке нужен интернет и развёрнутый Apps Script.
